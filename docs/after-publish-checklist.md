# 公開後の確認メモ

## スマホで見る項目(本番ドメイン https://seminar-vote-app.vercel.app)
1. 配られたQRを読み取り、投票画面が開く(動画が「投票中」でないときは、待機表示)。
2. 自分の動画のとき、「あなたの動画です」と出て、投票欄が出ない。
3. 他人の動画で、技術・インパクトを選んで送信 → 内容が表示される。締切まで上書きできる。
4. /result を開き、発表段階に応じた順位だけが出る(段階0は「お待ちください」)。
5. 横向き・縦向きで、文字が切れない。

## QR画面の印刷手順
1. **公開URL(https://…vercel.app)で** /admin にログインする。
2. 同じアドレスで /admin/qr を開く(QRの先頭の部分が、開いたアドレスから自動で入る)。
3. 緑の表示「QRの先頭: https://…」を確認する。黄色の警告が出たら、localhostやhttpのまま。公開URLで開き直す。
4. 「印刷する」で印刷し、点線に沿って切り分け、1人1枚ずつ配る。QRは本人専用なので、見せ合わないよう伝える。
5. 配る前に、1枚をスマホで読み取って、投票画面が開くことを確かめる。

## 管理画面の使い方
- 管理画面は、https の本番ドメイン、または自分のパソコンの localhost で使う(http の他アドレスでは、Cookieが安全に扱えない)。
- 当日の流れ:動画ごとに「投票開始」→ 全員の投票済みを確認 → 「締切」。放映できない動画は「放映不可」。最後に発表段階を 1→2→3 と進める。
- 全データのリセットは確認ダイアログ付き。本番直前の練習のあとに行う。

## ログインがロックされたとき
- パスワードを何度も間違えると、一定時間ログインできなくなる(全体の上限にも達しうる)。
- 画面に出る待ち時間が過ぎるのを待つ。急ぐときは、Vercel の再デプロイ(または再起動)で記録が消える(記録はメモリ上のため)。
- パスワードを忘れたら、Vercel の環境変数 ADMIN_PASSWORD を新しい値に変えて再デプロイする(12文字以上)。
